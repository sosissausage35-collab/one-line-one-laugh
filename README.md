A tiny deterministic TypeScript program that writes one funny line to `/output/entry.txt` for make.fun's "One Line, One Laugh" bounty — a single self-contained joke, short enough to read in a breath, judged in blind pairwise rounds by a comedy-editor judge. No network, no randomness: the same line on every run.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (the grader runs Node 22.23.4). The entry is written to `/output/entry.txt` (89 characters, within the 1–140 gate).
